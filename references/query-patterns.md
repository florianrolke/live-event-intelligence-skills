# Query Patterns

Use these as templates. Replace bracketed variables and generate multiple variants.

## Broad Event Discovery

```text
[niche] conference [year]
[niche] events [year]
[adjacent niche] conference [year]
[asset/business model] conference [year]
[industry term] expo [year]
```

## Official Source Discovery

```text
site:[official association domain] events [year]
site:[industry publication domain] events [niche] [year]
site:[association domain] annual meeting [year]
site:[association domain] convention [year]
```

## Named Event Research

```text
[event name] speakers [year]
[event name] exhibitors [year]
[event name] sponsors [year]
[event name] attendees LinkedIn
[event name] agenda speakers
[event name] app exhibitors sponsors
```

## Person LinkedIn Lookup

```text
site:linkedin.com/in "[person name]" "[company]"
site:linkedin.com/in "[person name]" "[event or niche keyword]"
"[person name]" LinkedIn "[company]"
"[person name]" LinkedIn "[title or niche]"
```

## Company LinkedIn Lookup

```text
site:linkedin.com/company "[company name]" LinkedIn
site:linkedin.com/company "[company name]" "[industry keyword]"
"[company name]" LinkedIn company
```

## Attendance/Post Snippets

```text
"[event name]" "LinkedIn" "[company]"
"[event name]" "attending"
"[event name]" "exhibiting"
"[event name]" "booth"
"[event name]" "#[hashtag]"
```

## Local/Suburb Discovery

```text
"[niche]" events "[city]"
"[niche]" conference "[city]"
"[niche]" association "[city]" events
"[profession]" society "[state]" conference
site:.org "[niche]" "[city]" "events"
```
